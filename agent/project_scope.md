PROJECT SCOPE — XPLOITAI (PHASE 1)

Purpose:
XploitAI Phase 1 is a cyber attack lifecycle simulation platform.
It models how penetration tests progress across reconnaissance,
enumeration, exploitation, privilege escalation, and proof of
compromise — without executing real attacks.

Primary Goal:
To implement the control plane of XploitAI, including AI reasoning,
policy enforcement, simulation-based execution, and attack visualization.

Out of Scope (STRICT):
- No Kali Linux integration
- No real exploit execution
- No SSH or network scanning
- No Metasploit, Nmap, or OS commands
- No VM interaction of any kind

Target Users:
- Cybersecurity students
- Instructors
- Demonstrators of attack logic

Core Features (Phase 1 Only):
- AI-driven action selection (decision-making only)
- Policy-based validation of attack steps
- Simulated execution of attack actions
- Attack timeline and kill-chain visualization
